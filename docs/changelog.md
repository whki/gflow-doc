## v1.4.0 · 2026-10-26

### GFlow Engine（开源引擎）

#### 新功能

- 转办、委派归还、改派、收回落流转轨迹行：时间轴与已办完整保留每一任办理人，改派后原受理人可继续查看单据与已办记录，轨迹行锚定真实操作时刻
- 已办列表与实例联合查询支持转办人命中
- 恢复终态收回（整单重开）：末节点审批人在窗口期内取回退回本人待审
- 回退目标放宽为任意已完成上游节点，补拓扑校验与并行网关守卫，退回清理的旧票统一落作废标记并记录退回原因
- 发起业务键幂等宽限窗口：终态实例同业务键在宽限期内重试返回既有单

#### 问题修复

- 会签变量合并剥离引擎保留键，减签重评出口补剥离，子票转办轨迹行挂父任务
- 任务落库与认领唤醒改实例行锁内终审；挂起实例上晚到的任务冻结落库，恢复后随级联激活
- 减签限制加签子任务仅加签人本人可移除并留痕操作人；任务变量拒写引擎保留键，封住改派与代审标记被办理人改写
- 终止级联子实例并逐单落 terminated 事件；部署期拒绝拓扑环；任务落库瞬时故障改哨兵标记由节点层重试

### GFlow Platform（商业版）

#### 新功能

- 审批通知直达 IM 个人：钉钉工作通知、企业微信应用消息、飞书消息卡片三种渠道，待办 / 抄送 / 驳回 / 催办定向送达经办人本人，卡片一键进入审批页免密办理，链接为一次性票据防转发冒用
- 通讯录同步与账号打通：录入企业应用凭证即启用，一键同步部门与成员，按手机号自动绑定账号；每日凌晨自动全量同步，离职成员自动停用
- 免登录进入：钉钉 / 企业微信 App 内打开即以本人身份登录，桌面端支持钉钉扫码登录（可选），支持与自有系统经标准 JWT 互信一键跳入（可选）
- IM 渠道配置按租户独立设置，多企业各用各的应用凭证
- 外部系统集成 API-Key 与 Webhook：外部系统以系统身份调用审批接口、接收审批事件回调；重复发起幂等，同业务键在宽限期内返回既有单；密钥支持有效期与吊销，投递失败可在管理界面一键重发
- 转办、委派归还、改派全程留痕：时间轴与打印单显示每一任办理人，改派后原受理人仍可跟踪单据进度
- 终态收回恢复：末节点审批人在窗口期内可取回自己审完的单退回本人待审，窗口时长在流程设计器按流程配置
- 退回目标放宽为任意已完成的上游节点，退回原因随单据留痕
- 登录日志独立记录，保留期可配置；审计日志操作类型统一规范

#### 问题修复

- 停用、删除用户的登录即时失效，修改密码后原有登录自动下线
- 系统报错统一中文提示，提升通知投递与系统运行稳定性
- 修复表单设计器复制粘贴或容器拖入产生重复数据键、填写一处全表同列联动的问题，填写、查看、打印统一按唯一键修复
- 升级 x/net、x/crypto、x/image、pgx 等依赖，消除可达安全漏洞

## v1.2.0 · 2026-09-14

### GFlow Engine（开源引擎）

#### 新功能

- 审批节点配置重构：审批人、审批方式（依次 / 会签 / 或签）、找不到审批人时的处理、驳回与退回规则，统一在一处配置
- 发起和审批时，可以提前看到后续每个环节由谁来审批
- 审批人是发起人时自动跳过，不用自己审自己
- 驳回只能退到前面的环节，不能跨并行分支乱退
- 申请列表支持按状态筛选和统计
- AI 审批支持读取附件，图片和文档都能识别
- 多租户隔离更严格，跨租户操作一律拒绝
- 支持多副本部署：跨副本执行接入分布式锁，实例变更广播缓存失效，定时任务按槽位去重

#### 问题修复

- 修复了一批权限漏洞，越权操作全部拦截
- 修复多服务器部署时，同一申请可能被重复处理的问题
- 修复加签、减签、终止等操作时，审批状态可能错乱的问题
- 修复待签收任务的可见性和签收状态残留问题
- 修复已作废的申请仍出现在待办、委托归还后缺少审批意见的问题
- 修复流程重新驱动时，AI 被重复调用的问题

### GFlow Platform（商业版）

#### 新功能

- 新增移动端：手机上直接发起申请、处理审批、查看进度与抄送
- 审批中心收件箱式改版：待办 / 已办 / 我发起的 / 抄送我集中处理，支持按状态筛选、键盘快速流转
- 公共待办支持签收、抢单，先认领再审批
- 界面焕新：列表页统一布局更整齐，发起申请页改版更清爽，审批详情页重新设计，登录页全新品牌视觉
- 表单与打印更规范：只读内容直接显示为文本，打印单据明细表格化、金额千分位、支持合计
- 工作台「最近活动」改为与我相关的动态，点击直达审批详情
- 流程设计器支持更多审批配置：会签 / 或签、找不到审批人怎么办、驳回规则，设计器里直接设置
- 发起和审批时可预览后续审批人，可开启「审批人是发起人时自动通过」
- 支持接入外部表单：业务系统现有的表单直接接入审批，审批结果自动回传；嵌入更稳定，审批页按业务名称显示表单内容

#### 问题修复

- 驳回、退回等操作的报错统一改为易懂的中文提示
- 修复已被 AI 拒绝的申请还能重复拒绝、切换页签后数据不刷新的问题
- 修复会签和顺序审批下「发起人自动通过」不生效的问题
