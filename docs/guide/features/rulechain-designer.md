# 规则链设计器

<div class="lead">
商业版四大自研部件之一。可视化编排 RuleGo 规则链——审批通过后的入账、通知、写第三方系统，拖节点连线即可，不用手写规则链 JSON。
</div>

## 为什么审批平台需要规则链设计器

`automation` 节点能调用任意 RuleGo 规则链，但开源版里规则链只能手写 JSON。gflow 把这块补齐了：**规则链即流程、规则链也可以像流程一样拖出来**。

```
流程设计器：审批怎么走（人 + 路由）
规则链设计器：系统做什么（自动化动作）
两者经 automation 节点无缝衔接
```

## 设计器能力

- **拖拽编排**：节点面板 → 画布连线，与流程设计器同源的交互习惯
- **节点生态**：RuleGo 标准组件全部可用——数据转换、脚本、数据库、消息队列、邮件、HTTP 调用等
- **在线调试**：规则链 test 接口即时验证，输入样例消息看每节点输出
- **部署开关**：`disabled` 标记控制规则链是否生效，保存即更新；列表页可查版本与运行记录
- **租户隔离**：规则链按 `tenant_id` 隔离，与流程引擎的执行池一致

## 与流程的联动

流程设计器里拖入「自动化」节点，选择已编排好的规则链：

```json
{
  "type": "automation",
  "name": "报销自动入账",
  "configuration": {
    "targetId": "expense_auto_book"
  }
}
```

审批走到该节点 → 引擎调用规则链 → 入账/通知/回写 ERP 全自动。反过来，规则链里的节点也可以通过 REST API 发起审批流程——**流程驱动自动化，自动化也能发起流程**。

## 智能体联动

规则链里可以挂 AI 节点（基于 rulego-components-ai），配合[智能体管理](/guide/features/ai-approval)构建「审批 + AI + 自动化」的组合拳：AI 预审 → 低风险走自动化直通 → 高风险转人工会签。

## 开源版说明

引擎层的 `automation` 节点开源（按[节点类型总览](/guide/features/nodes)配置即可）；**可视化设计器界面**属于 gflow 商业版（源码交付，见[价格](/pricing)）。
