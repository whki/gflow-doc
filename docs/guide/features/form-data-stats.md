# 表单数据统计

<div class="lead">
选一个流程，自动生成整版统计看板：数字字段的合计与均值、选项字段的占比、按部门/发起人/月份的分组透视，无需任何配置。本文面向管理员，说明看板怎么读、筛选口径怎么选、哪些字段能统计。
</div>

## 入口与权限

管理员登录后，在「审批中心 → 表单数据」打开（菜单对普通员工不可见，仅授权管理员与工作流管理员）。页面左侧选流程、切时间范围，看板即时刷新；右上角「导出报告」一键导出本次统计。

## 看板自动生成

选中流程后，系统读取该流程绑定的表单定义，自动识别可统计字段并生成三块看板，全部字段默认参与，不需要手工建图表：

| 看板区 | 回答的问题 | 参与字段 |
|---|---|---|
| 指标卡 | 这批单合计多少、平均多少、最大最小多少 | 数字、金额字段 |
| 选项占比 | 各选项被选了多少次、占百分之几 | 单选、多选、开关字段 |
| 分组透视 | 按部门/发起人/月份/某选项字段切开看 | 有数字字段的流程 |

**选项占比**的两个细节：选项全集来自表单定义，零票的选项也会显示 0%，不会"凭空消失"；多选题一票可命中多个选项，占比分母始终是单据数，所以各选项百分比之和可能超过 100%。

**分组透视**在右上角切换维度：按部门、按发起人、按月，以及按任意选项字段（如按请假类型看合计天数）。每个分组行显示样本数与各数字字段的聚合值，支持导出 CSV。发起人这类维度取值可能上千，表格默认只展示前 50 行，鼠标悬停可看全名。

## 筛选与口径

| 筛选项 | 说明 |
|---|---|
| 时间范围 | 本月 / 本季 / 本年 / 自定义日期区间 |
| 含进行中 | 默认只统计**已出结果**的单据（通过、拒绝、撤回、终止等）；勾选后并入运行中的单，适合看"截至目前"的实时盘面 |
| 统计字段 | 抽屉里逐字段勾选，取消的字段不参与指标卡、占比与分组，右上角徽标显示已选数 |

看板顶部的覆盖率条提示数据质量：「参与统计 N 份 · 数据完整」，或「N 份字段值缺失或无法解析，已跳过」——跳过的单据不计入分母，脏数据一眼可见。

两个容易疑惑的口径：

- **刚完结的单没出现**：统计结果有分钟级缓存，且单据从结束到归档有短暂窗口，等一分钟点「刷新」即可。
- **提示"缩小时间范围"**：单个流程时间窗内的单据超过 5 万份时，系统直接拒绝计算而不是慢慢拖死数据库。按月或按季切窗口即可。

## 明细数据与导出

「明细数据」页签逐单列出每份表单的填写值（发起人、发起时间、状态、各字段值），与统计看板共用同一套筛选口径，先看汇总、再下钻到单，支持分页，可导出 CSV（最多 2000 条）。三个导出入口都是 CSV：

| 导出入口 | 内容 |
|---|---|
| 导出报告（右上角） | 整版报告：指标卡、选项占比、当前分组透视三段，带流程名与统计范围抬头 |
| 分组透视「导出 CSV」 | 当前维度的分组表（维度、各指标、样本数） |
| 明细数据「导出 CSV」 | 逐单明细行 |

## 哪些字段能统计

为避免敏感信息进入报表，只有以下类型的字段参与统计，其余字段（单行/多行文本、富文本、附件、密码等）结构上就不出现在看板里：

| 字段类型 | 统计形态 |
|---|---|
| 数字、金额 | 指标（合计/平均/最小/最大） |
| 单选、下拉、开关 | 占比 |
| 多选 | 占比（一票多桶） |
| 日期 | 分组维度（按字段值所在月份） |
| 人员、部门 | 分组维度 |
| 子表字段 | 按行展开统计（矩阵题每行计一次） |

## 接口

看板消费两个 REST 接口，可被外部系统集成复用：可统计字段探查 `GET /api/v1/workflow/form-statistics/fields`、聚合查询 `POST /api/v1/workflow/form-statistics/aggregate`（请求体声明指标/占比/分组计划）。字段说明见 [REST API](/guide/api)，完整 Schema 以 Swagger 为准。
